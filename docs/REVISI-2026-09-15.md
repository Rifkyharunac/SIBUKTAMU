# Revisi tujuan layanan dan tanda tangan

Pilihan pada tahap kedua buku tamu kini mengikuti lembar disposisi terbaru.
Pilihan **Kepala Dinas** tidak dimasukkan. Tujuan yang tersedia adalah Kabid
P5TK, Kabid PHI Wasnaker, Kabid Perencanaan KT, Kabid PKTP3, Kabid PKTDT,
Ka. UPT Wasnaker Wilayah I, Ka. UPT Wasnaker Wilayah II, dan Sekretariat Dinas.

Sekretariat Dinas ditempatkan paling bawah dan dibagi menjadi **Kepegawaian**,
**Program**, **Sub Keuangan dan Aset**, serta pilihan **Lainnya**. Jika Lainnya
dipilih, tamu wajib menuliskan keperluannya.

Kanvas tanda tangan juga diperbaiki agar tinta langsung muncul sejak sentuhan
atau klik pertama. Kanvas tidak lagi diinisialisasi ulang ketika goresan pertama
dibuat, sehingga bagian awal tanda tangan tidak terpotong.

Untuk database yang sudah pernah menjalankan revisi sebelumnya, terapkan migrasi
baru sebelum melakukan deployment:

```bash
npm run db:migrate:remote
```

Migrasi `0005_revised_visit_destinations.sql` menonaktifkan pilihan lama tanpa
menghapusnya agar riwayat kunjungan terdahulu tetap tersimpan.
