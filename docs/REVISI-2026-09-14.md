# Revisi layanan berdasarkan struktur organisasi resmi

Katalog pengisian buku tamu telah disesuaikan dengan lima bidang pada struktur
organisasi Dinas Tenaga Kerja dan Transmigrasi Provinsi Sulawesi Tengah. Setiap
bidang menampilkan seksi atau layanan yang berada di bawahnya dan memiliki satu
pilihan **Lainnya**.

Jika tamu memilih **Lainnya**, formulir langsung menampilkan kolom wajib untuk
menjelaskan keperluan. Pada tahap **Detail dan konfirmasi**, bagian Keperluan
menampilkan isi yang diketik tamu, bukan kata "Lainnya". Uraian tersebut juga
disimpan di database dan dipakai dalam notifikasi petugas.

Migrasi `0004_official_organization_catalog.sql` mengaktifkan lima bidang dan 19
pilihan layanan resmi. Data master lama dinonaktifkan, bukan dihapus, sehingga
riwayat kunjungan yang telah tercatat tetap dapat dipertahankan. Setelah menarik
kode revisi pada lingkungan yang sudah berjalan, terapkan migrasi dengan:

```bash
npm run db:migrate:remote
```

Sesudah migrasi selesai, jalankan deployment aplikasi seperti biasa. Sebelum
digunakan oleh tamu, periksa nomor WhatsApp admin untuk masing-masing bidang pada
menu **Master Bidang**.
